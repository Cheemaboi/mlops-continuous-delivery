# Submission screenshot checklist

Do not replace these descriptions with fabricated screenshots. Capture the following after the corresponding real event:

- `ci-success.png`: passing pull-request CI.
- `release-workflow.png`: tag-triggered release workflow.
- `ghcr-images.png`: GHCR tags `1.2.0`, `1.3.0`, and `latest`.
- `staging-success.png` and `health-check.png`: staging and its health response.
- `production-approval.png` and `production-success.png`: approval and production deployment.
- `rollback-health.png`: `/health` after redeploying immutable `1.2.0`.
